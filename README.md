### ✨ Features

- 🌐 **Multilingual Interface**: Full native localization for **English (default)**, **Русский**, and **中文** with dynamic on-the-fly language switching in Settings.
- ⚡ **Smart Priority Queue**:
  - **`⚡` Priority**: Move urgent downloads to the front of the queue.
  - **`▲` / `▼` Reorder**: Customize queue execution order.
  - **Context Menu**: Right-click actions (Download next, Move up/down, Copy URL, Retry failed, Remove).
  - **Real-time Streaming**: Instant live speed (MB/s), downloaded size, and accurate ETA without freezing.
- 🎬 **Hero Metadata Preview**: Automatically extracts title, cover art thumbnail, and available resolutions (`1080p`, `720p`, `480p`, `Best`).
- 🚀 **Dual Engine Support**:
  - **Universal Engine**: Powered by yt-dlp, supporting 1000+ streaming services and social media platforms.
  - **Playerjs Engine**: Direct high-speed capture from Playerjs/KVS sites without re-encoding.
- 🛡 **CDP Browser Mode**: Built-in human emulation to bypass Cloudflare/CDN bot protections by capturing media directly from playback.
- 🎵 **Audio Extraction**: 1-click conversion to high-bitrate MP3 (192 kbps).
- ⚙ **Proxy Support**: Full HTTP & SOCKS5 proxy integration for bypassing regional geo-blocks.
- 🔔 **System Tray & Toast Notifications**: Background task execution with notifications upon completion.
- 📦 **Automated FFmpeg**: Single-click automated setup if FFmpeg is not already installed on your system.
