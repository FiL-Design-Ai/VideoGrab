VideoGrab — загрузчик видео
===========================

1. Распакуйте папку VideoGrab куда угодно (exe без папки _internal не работает!).
2. Запустите VideoGrab.exe. Python не нужен, права администратора не нужны.
3. Вставьте ссылку на видео → выберите режим/качество → «СКАЧАТЬ».
   Файлы сохраняются в «Загрузки\VideoGrab» (папку можно сменить).

Для режима «Аудио (MP3)» и склейки потоков нужен ffmpeg: если в шапке горит
красное предупреждение, нажмите «Скачать ffmpeg» (нужен интернет, ~110 МБ,
скачивается один раз).

Если сайт не пускает ваш IP (плеер пишет «Video file not found» или ошибка 403):
включите свой VPN/прокси и укажите его адрес в поле «Прокси» (например,
127.0.0.1:7897) — тогда загрузка пойдёт через него.

Скачивание предназначено для личного использования контента, на которое у вас
есть разрешение. Уважайте авторские права.

Windows 10/11 x64. Версия 1.2.0.
- Превью и заголовок видео при вставке ссылки
- Уведомления со звуком по окончании загрузки
- Сворачивание в системный трей (возле часов)
